# Google Photos Review Intelligence Dashboard

## Project Overview

Every day, apps receive thousands of user reviews. For companies, manually reading and understanding all these reviews becomes difficult and time-consuming.

This project focuses on analyzing Google Photos reviews using Data Science and NLP techniques. The dashboard helps understand customer sentiment, identify common complaints, and visualize user feedback in an easy and interactive way.

The main goal of this project is to convert raw user reviews into meaningful insights that can help improve product quality and customer experience.


## Problem Statement

Companies often struggle to:
- understand customer feedback quickly
- identify recurring issues
- track customer satisfaction
- analyze large amounts of review data efficiently

Manual analysis is not scalable and can miss important patterns hidden inside reviews.



## Solution

This dashboard automates the review analysis process by using:
- Sentiment Analysis
- WordCloud Visualization
- Keyword Extraction
- Correlation Heatmaps
- Interactive Data Visualizations

The system helps in identifying both positive and negative user experiences from Google Photos reviews.

## Features

- Interactive Streamlit Dashboard
- Sentiment Distribution Analysis
- Positive, Negative & Neutral Review Analysis
- Auto-generated Insights
- Complaint Keyword Detection
- WordCloud Visualizations
- Correlation Heatmap
- Polarity Distribution Histogram
- Download Processed Dataset Feature
